# Tapes of real instruments

Each `.tape` here is the traffic of a hardware check (**Tools ▾ → Hardware check…**, **Save tape…**) on a real instrument. The tests play every one back through its driver: each step must come out as it did on the hardware.

Name it after the model and firmware, e.g. `66321D-A.03.01.tape`. The serial number is taken out where possible; look through the file (it is text) before you share it.

A test that fails here means a driver change altered what it makes of a real instrument's answers. If the new result is the right one, make a new tape; don't edit the old one.
